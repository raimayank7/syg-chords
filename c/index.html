C chords

Every chord built on the note C: twelve types, each on guitar, ukulele and keyboard.

About chords on C

All the chords on this page share the root C; they differ in the notes added above it. The major chord takes the third and fifth notes of the C major scale, whose notes are, by the names used on this site, C, D, E, F, G, A, B. Lower the third and the chord is minor; add a seventh, sixth or ninth for the four-note chords; replace the third with the second or fourth for the suspended chords. The formulas are on how chords are built.

The key of C major

In the key of C major, the chords that belong together are: C (I), Dm (ii), Em (iii), F (IV), G (V), Am (vi), Bdim (vii°). The first, fourth and fifth are the main chords; start with those three and add the sixth, Am, for contrast. The same seven chords, starting from Am, make the key of A minor.

Where to start

Learn C and Cm first, then C7. On guitar, look at the first chart on each page: it is the easiest shape. Where the first shape is a barre chord and that is still hard for you, the page for the power chord gives a two-finger stand-in, and a capo can move easier shapes to this root: see capo and transposing.
